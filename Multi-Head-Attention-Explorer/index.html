HOW IT WORKS

Inside Multi-Head Attention

01

Input tokens

Split the sentence into individual tokens.

02

Q, K and V

Create query, key and value vectors using weights.

03

Multiple heads

Each head uses its own weights and can learn a different view.

04

Attention scores

Compare queries and keys using scaled dot products.

05

Softmax

Convert scores into probabilities that sum to 1 per row.

Learning demo: This explorer uses randomly initialized vectors and weights. The patterns are not learned language relationships and may change every time you generate new weights.
