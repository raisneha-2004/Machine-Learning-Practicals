# Multi-Head Attention Explorer 🧠

An interactive, browser-based project to understand how **Multi-Head Attention** works in Transformer architectures using JavaScript, HTML, and CSS.

This project visualizes how different attention heads can assign different attention scores to tokens in the same sentence. It is designed as a beginner-friendly learning tool for understanding the basic mechanics of attention.

## 📌 Project Overview

In Transformer models, Multi-Head Attention allows the model to process information from different representation spaces.

Instead of using just one attention mechanism, multiple attention heads calculate their own attention patterns. Each head can potentially focus on different relationships between tokens.

This project demonstrates that idea through interactive attention heatmaps, without requiring a pretrained model or any external libraries.

## ✨ Features

- **Sentence Input:** Enter a sentence containing up to 12 tokens.
- **Multiple Attention Heads:** Choose between 1, 2, 4, or 8 heads.
- **Attention Heatmaps:** View a separate, colour-coded attention matrix for each head.
- **Token Inspector:** Select a token row to see which token receives the highest attention from each head.
- **Random Weights:** Generate new random weights to explore different attention patterns.
- **Causal Masking:** Prevent tokens from attending to future tokens.
- **Attention Values:** Show or hide the numerical attention scores in each cell.
- **Probability Validation:** Check that each attention row sums to approximately 1.
- **Responsive Design:** Use the explorer on desktop or mobile screens.

## 🧩 How It Works

### 1. Tokenization

The input sentence is split into individual tokens using whitespace.

Example:

`The cat sat on the mat`

Tokens: `The`, `cat`, `sat`, `on`, `the`, `mat`

### 2. Query, Key, and Value Vectors

The demo creates random token embeddings and uses randomly initialized projection weights to calculate Query (Q), Key (K), and Value (V) vectors.

- **Query (Q):** Represents what a token is looking for.
- **Key (K):** Represents what a token offers for comparison.
- **Value (V):** Represents the information used to calculate the attention output.

### 3. Attention Score Calculation

The similarity between queries and keys is calculated using scaled dot-product attention:

`Attention Scores = (Q × Kᵀ) / √dₖ`

Here, `dₖ` is the dimension of the key vectors.

### 4. Softmax

Softmax converts the scores into attention probabilities. Each row sums to approximately 1.

### 5. Multiple Attention Heads

Each head uses its own randomly initialized projection weights, producing a different attention matrix.

The heatmaps make it easy to compare the patterns generated by different heads.

### 6. Causal Masking

When causal masking is enabled, each token can attend only to itself and earlier tokens. Future-token positions are masked before softmax.

This demonstrates a masking technique commonly used in autoregressive Transformer decoders.

## 📊 Understanding the Heatmap

- **Rows:** Tokens performing the attention operation (queries).
- **Columns:** Tokens being attended to (keys).
- **Brighter cells:** Higher attention probabilities.
- **Selected token:** Highlights the row being inspected.
- **Token Inspector:** Displays the strongest attention target for each head.

## ⚠️ Important Note

This is an educational visualization, not a trained language model.

The embeddings and projection weights are randomly initialized. Therefore, the heatmaps do not represent learned grammatical relationships or meaningful linguistic understanding.

The project demonstrates the mechanics of scaled dot-product attention and the idea of using multiple attention heads. It does not implement a complete Transformer model, including the concatenation and final output projection of all heads.
